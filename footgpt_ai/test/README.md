# Flutter tests

| Directory | Purpose |
| --- | --- |
| `test/unit/` | Pure Dart (paths, models, exceptions) |
| `test/` root | Widget tests (`widget_test.dart`, tactics, navigation) |
| `test/widget/` | Additional widget suites as features grow |
| `integration_test/` | Device/emulator flows (`flutter test integration_test`) |

Run: `flutter test`
